## 🖤 L'ABYSSE S'ÉVEILLE (PRÉSENTATION)
**Cassidy Bot** n'est pas un simple bot. C'est une entité destructrice fusionnant la puissance brute de **Sung Jin-Woo** 🗡️ et la maîtrise occulte du Ninjutsu de **Naruto** 🍥. 
Conçu pour dominer vos groupes Messenger, il soumet le tchat à l'autorité absolue du Monarque.
* 👑 **Esthétique S-Rank** | Interface *Dark Fantasy* noire, or impérial et reflets violets abyssaux.
* ⚡ **Moteur D'Ombre Ultra-Rapide** | Exécution instantanée sans aucun temps de latence.
* 💬 **Genjutsu Conversationnel** | IA réactive capable d'imiter le raisonnement humain.
* 📩 **Extraction Silencieuse** | Réponses secrètes envoyées directement en MP.
* ⚙️ **Domaine du Souverain** | Commandes de modération impitoyables pour purger les perturbateurs.

## ⚙️ RITUEL D'EXÉCUTION (INSTALLATION)
Injectez le code source dans votre serveur pour éveiller le monarque :
```bash
# 1. Extraire les fichiers de l'Abysse
git clone [https://github.com/flackodisk12-sudo/Cassidy-bot.git](https://github.com/flackodisk12-sudo/Cassidy-bot.git)
# 2. Entrer dans la Chambre du Souverain
cd Cassidy-bot
# 3. Injecter l'énergie de Mana (Dépendances)
npm install
# 4. Déclencher l'Éveil
npm start
